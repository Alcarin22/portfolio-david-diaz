Gestión Taller GTA V RP

Una aplicación de gestión interna que reúne facturación, empleados, fichajes y estadísticas para un taller de roleplay.

El punto de partida

La actividad de un taller implica mantener información de empleados, registrar trabajos y controlar tiempos. El proyecto reúne estas tareas para dar estructura a la gestión diaria.

Áreas de la aplicación

  • Facturación y consulta de la actividad del taller.
  • Gestión de empleados y registro de fichajes.
  • Estadísticas para consultar la actividad.
  • Autenticación mediante Discord OAuth2.

Enfoque técnico

Angular para la interfaz, Spring Boot para la lógica de negocio y MySQL para la persistencia. Discord OAuth2 proporciona el punto de entrada para la autenticación.
