Gestión Taller GTA V RP

Aplicación Full Stack para centralizar la gestión interna de un taller dentro de una comunidad de GTA Roleplay.

Full StackAngular + Spring BootRepositorio público

El punto de partida

La actividad diaria de un taller requiere coordinar empleados, facturación, tiempos de trabajo, servicios y documentación. El proyecto reúne estas tareas en una única aplicación para estructurar la gestión interna y reducir procesos dispersos.

Áreas de la aplicación

  • Creación de facturas individuales y por lotes.
  • Historial de facturación con filtros y paginación.
  • Gestión de empleados, rangos y permisos.
  • Registro de fichajes y tiempo trabajado.
  • Gestión de primas semanales, convenios y tasaciones.
  • Consulta de precios, servicios, vehículos y documentación interna.
  • Autenticación mediante Discord OAuth2.

Enfoque técnico

El frontend está desarrollado con Angular y TypeScript, mientras que el backend utiliza Java y Spring Boot para exponer la API REST y gestionar la lógica de negocio. MySQL proporciona la persistencia de datos. La autenticación se realiza mediante Discord OAuth2 y las sesiones protegidas utilizan JWT. Las operaciones sensibles vuelven a validar los permisos en backend mediante Spring Security.

Estado del proyecto

El código fuente está disponible públicamente en GitHub. La aplicación está destinada al uso interno de la comunidad para la que fue desarrollada, por lo que su despliegue no se presenta como una demo pública del portfolio.

GT7 Daily Bot

Bot de Discord que recopila, procesa y publica automáticamente información sobre las Carreras Diarias de Gran Turismo 7.

Discord BotAutomatizaciónRepositorio público

Objetivo

El proyecto automatiza la publicación semanal de las Carreras Diarias de Gran Turismo 7 dentro de una comunidad de Discord. La información procedente de distintas fuentes públicas se procesa antes de generar una publicación estructurada y fácil de consultar.

Funcionalidades actuales

  • Publicación de las Carreras Diarias A, B y C.
  • Comando /daily para solicitar una actualización manual.
  • Mensajes estructurados mediante embeds de Discord.
  • Publicaciones provisionales cuando todavía existen datos pendientes de confirmación.
  • Actualización de mensajes existentes para evitar publicaciones duplicadas.
  • Persistencia del estado de las publicaciones semanales.
  • Comprobaciones automáticas mediante tareas programadas.

Enfoque técnico

El bot se ejecuta sobre Node.js y utiliza JavaScript y Discord.js para la integración con Discord. Axios y Cheerio se encargan de obtener y procesar información pública, Luxon gestiona fechas y zonas horarias y node-cron programa las comprobaciones automáticas.

Fuentes de información

Actualmente el proyecto combina información pública de GTSH-Rank y GT GridStats. Al depender de fuentes externas, cambios en la estructura de sus páginas pueden requerir adaptar los procesos de extracción.

Estado del proyecto

GT7 Daily Bot continúa en desarrollo. El repositorio público permite consultar su evolución, arquitectura y código fuente.
